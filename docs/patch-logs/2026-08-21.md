# Patch log — 21/08/2026

## beta 0.39

- **Envio em massa para cadência corrigido**: seleções grandes (centenas de leads, ex.: 683) falhavam ao enviar para uma cadência. Agora o envio é processado em lotes internos, sem limite prático de seleção.
- O mesmo tratamento em lotes vale para a ação de **descartar leads** em massa.

## beta 0.40 — Progresso no envio em massa

- Ao enviar leads em massa para uma cadência (ou descartar), agora aparece uma barra de progresso com status: enviando, concluído ou falhou.
- O envio é feito em lotes, mostrando quantos leads já foram processados do total.
- Se algo falhar, a mensagem de erro aparece e é possível tentar novamente sem refazer a seleção.

## beta 0.41 — Cadência trava enquanto houver aprovação pendente

- Corrigido: a cadência avançava para o próximo passo mesmo com uma mensagem anterior do mesmo lead ainda aguardando aprovação (HITL).
- Agora, antes de executar qualquer passo (modo normal ou agêntico), o sistema verifica se existe aprovação pendente para o lead. Se existir, a inscrição é pausada com motivo `hitl_pending` e retomada automaticamente após aprovar/enviar.
