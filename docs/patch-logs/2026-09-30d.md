# beta 0.71 — 30/09/2026

## Correções
- **Vários telefones no mesmo campo.** Quando a planilha trazia dois números juntos (ex.: "34-99646-7696, 34-99239-7088"), o app juntava tudo em um número inválido. Agora ele separa, escolhe o celular primeiro e verifica esse número no WhatsApp.
- **Telefone fixo não é mais tratado como "sem WhatsApp".** Só é marcado como sem WhatsApp quando a Hook7 confirma.
- As aprovações da Arrecadeei que falharam voltaram para Aprovações.
