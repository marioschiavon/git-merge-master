# Patch Logs — Leaderei

Notas de versão em linguagem simples, para clientes acompanharem o que muda no app.

Cada arquivo cobre um dia e segue o mesmo formato: **Novidades**, **Melhorias** e **Correções**.

## Índice

- [19/08/2026](./2026-08-19.md) — beta 0.33 → beta 0.38

## Como manter

A cada nova versão publicada (`APP_VERSION` em `src/lib/version.ts`), criar ou atualizar o arquivo do dia
(`docs/patch-logs/AAAA-MM-DD.md`) descrevendo as mudanças do ponto de vista do cliente, e adicionar a
data neste índice.
